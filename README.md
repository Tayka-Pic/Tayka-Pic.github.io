# tayka-pic.github.io

The public face of **Tayka** — one photo prompt a day, the same one for
everyone in the world at the same instant.

The app's source lives in a private repository. This one holds only what the
outside world needs to see:

| Path | What it is |
|---|---|
| `index.html` | Landing page. Where an invite link points until the App Store listing exists. |
| `privacy/index.html` | Privacy policy. The canonical copy — App Store submission requires a reachable URL. |
| `app-ads.txt` | Authorises Google to sell Tayka's ad inventory, so a spoofer cannot claim it. Takes effect once an App Store listing names this site as the marketing URL. |

Served by GitHub Pages at <https://tayka-pic.github.io>.
